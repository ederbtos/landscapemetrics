ℹ️ Como interpretar estes resultados

Gráfico de barras: proporção (%) da paisagem ocupada por cada classe de cobertura do solo — quanto maior a barra, mais dominante aquela classe na área analisada.

Tabela por classe: % Paisagem é a mesma proporção do gráfico; NP é o número de manchas (fragmentos) daquela classe — mais manchas geralmente indica maior fragmentação; ED é a densidade de borda (metros de perímetro por hectare) — quanto maior, mais recortada/irregular é a forma das manchas.

Cards no topo: SHDI (Diversidade de Shannon) mede quão heterogênea é a paisagem entre classes — perto de 0 significa que uma classe domina quase tudo, valores maiores indicam uma mistura mais equilibrada. Densidade de manchas e Densidade de borda são as mesmas ideias acima, mas em nível de paisagem inteira (todas as classes juntas), não por classe.

Visualização 2D (PCA) dos Clusters:
ℹ️ Como interpretar este gráfico

Cada ponto é UMA das suas análises salvas, projetada de dezenas de variáveis (proporção de classes + métricas de paisagem) para só 2 eixos (PCA 1 e PCA 2) — análises com composição de paisagem parecida ficam próximas no gráfico.

Cor = cluster atribuído pelo algoritmo. No K-Means, todo ponto pertence a um dos K grupos definidos; o Silhouette Score (perto de 1 = clusters bem separados, perto de 0 = sobrepostos) indica a qualidade do agrupamento. No DBSCAN, pontos marcados como Outlier (vermelho) não se encaixaram em nenhuma região densa — não é erro, é uma análise atípica em relação às demais.

Dica: Os nomes dos arquivos devem conter o ano (ex: meu_raster_2010.tif).
Dica: se o .zip não for reconhecido, selecione os arquivos soltos juntos no seletor. Mais de um polígono no arquivo é unido numa única área — cada GeoTIFF do lote é recortado por ela.

Resultados da Predição

Matriz de Transição de Probabilidade
ℹ️ Como interpretar esta predição

Linha sólida = histórico observado, extraído dos GeoTIFFs enviados. Linha tracejada = projeção calculada a partir da matriz de transição — ancorada no último ano observado, para não gerar um salto visual entre o dado real e a projeção.

Matriz de transição acima: cada célula é a probabilidade (0 a 1) de um pixel da classe da linha virar a classe da coluna no próximo intervalo — a diagonal mostra o quanto cada classe tende a permanecer estável.

⚠️ Método não-espacial (projeta só a proporção agregada de cada classe, não gera um mapa futuro) e assume que as probabilidades de transição observadas no histórico continuam constantes (estacionariedade) — trate como uma tendência, não como uma previsão exata.

📦 Métricas por Município em Lote

Envie o shapefile de municípios (ex.: malha do IBGE de uma UF) e um único GeoTIFF de cobertura do solo — calcula as métricas de fragmentação de TODOS os municípios do shapefile contra o mesmo raster.

Dica: se o .zip não for reconhecido, selecione os arquivos soltos (.shp, .shx, .dbf e, se possível, .prj) juntos no seletor.
ℹ️ Como interpretar esta tabela

Uma linha por município do shapefile enviado, com as mesmas métricas de nível de paisagem da Etapa 3 (SHDI, densidade de manchas, densidade de borda etc.) — calculadas contra o MESMO GeoTIFF para todos, então dá pra comparar municípios lado a lado.

Municípios que falharam (ex.: polígono fora da extensão do raster) aparecem só no resumo de erros no topo, não na tabela — o lote não para por causa de um município problemático.
